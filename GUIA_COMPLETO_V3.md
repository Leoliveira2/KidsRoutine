## 📱 **Como Usar em Múltiplos Dispositivos**

### **Primeira Configuração:**

1. **No primeiro dispositivo:**
   - Abra o aplicativo
   - Clique em "Criar Novo PIN"
   - Digite um PIN de 6 dígitos (ex: 123456)
   - **Anote este PIN em local seguro!**
   - Adicione as crianças e comece a usar

2. **Nos outros dispositivos (smartphone 2 e tablet):**
   - Abra o aplicativo
   - Digite o **mesmo PIN** criado no primeiro dispositivo
   - Clique em "Entrar"
   - Pronto! Os dados serão sincronizados

### **Sincronização Automática:**

O aplicativo sincroniza automaticamente quando:
- ✅ Uma criança completa uma missão
- ✅ Os pais acessam o dashboard
- ✅ Uma nova criança é adicionada
- ✅ Atividades são editadas

**Importante:** Todos os dispositivos devem usar o **mesmo PIN** para compartilhar os dados.

## 🎯 **Sistema de Qualidade (100%/50%/0%)**

Ao concluir uma missão, a criança (ou os pais) escolhe:

### **🌟 100% - Perfeito!**
- Fez a atividade completamente
- Ganha **100% dos pontos**
- Efeitos **completos** nas barras
- Badge verde com estrela

### **⚠️ 50% - Mais ou Menos**
- Fez parcialmente ou com pressa
- Ganha **50% dos pontos**
- Efeitos **reduzidos** nas barras
- Badge amarelo com alerta

### **❌ 0% - Não Fiz**
- Não realizou a atividade
- Ganha **0 pontos**
- **Sem aumento** nas barras
- Badge vermelho com X

## ❓ **Perguntas Frequentes**

### **1. O que acontece se eu esquecer o PIN?**
Infelizmente, não há recuperação de PIN por segurança. Você precisará criar um novo PIN e recomeçar. Por isso, **anote o PIN em local seguro!**

### **2. Posso usar em mais de 3 dispositivos?**
Sim! Não há limite de dispositivos. Basta usar o mesmo PIN em todos.

### **3. Preciso de internet para sincronizar?**
Sim, a sincronização entre dispositivos requer conexão com a internet. Mas o aplicativo funciona offline, sincronizando quando a internet voltar.

### **4. Os dados são seguros?**
Sim! Os dados são criptografados com seu PIN e armazenados de forma segura. Ninguém além de quem tem o PIN pode acessar.

### **5. Posso personalizar as missões?**
Sim! No Dashboard Parental você pode adicionar, editar ou remover missões conforme necessário para sua família.

### **6. Como resetar o progresso de uma criança?**
No Dashboard Parental, acesse o perfil da criança e clique em "Resetar Progresso". Isso apagará o histórico mas manterá o perfil.

### **7. Posso ter mais de uma família no mesmo dispositivo?**
Não diretamente. Cada PIN representa uma família. Se quiser gerenciar múltiplas famílias, use navegadores diferentes ou modo anônimo.

## 🔧 **Suporte Técnico**

### **Problemas Comuns:**

**Problema:** "Não consigo sincronizar entre dispositivos"
**Solução:** Verifique se está usando o mesmo PIN em todos os dispositivos e se há conexão com internet.

**Problema:** "O avatar não está mudando"
**Solução:** Certifique-se de que as missões estão sendo concluídas com qualidade (100% ou 50%). Missões puladas (0%) não afetam positivamente o avatar.

**Problema:** "Os gráficos não aparecem no dashboard"
**Solução:** É necessário ter pelo menos 3 dias de dados para os gráficos aparecerem.
